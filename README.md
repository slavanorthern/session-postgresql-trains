
# Сессионный проект по PostgreSQL

**Выполнил:** Ожиганов В. В.  
**Вариант:** 5  
**Тема:** Пригородные поезда и станции

## Описание проекта

Консольное приложение на Python для управления станциями
и маршрутами пригородных поездов.

Проект разработан на основе базы данных из предыдущих
заданий по PostgreSQL. В качестве примера используется
направление Новосибирск-Главный — Тогучин.

## Функциональные возможности

### Станции
- Просмотр списка станций
- Добавление новой станции
- Изменение названия, тарифной зоны и порядка следования
- Удаление станции с учетом связанных маршрутов

### Маршруты
- Просмотр маршрутов выбранной станции
- Добавление маршрута с начальной и конечной станциями
- Удаление маршрута по номеру строки

### Проверки данных
- Проверка типов и диапазонов вводимых значений
- Проверка длины названий станций
- Обработка ошибок PostgreSQL
- Использование параметризованных SQL-запросов
- Транзакции с откатом при ошибках
- Подтверждение удаления связанных объектов

Суррогатные идентификаторы используются только внутри
базы данных и не запрашиваются у пользователя.

## Используемые технологии

- Python 3.12
- PostgreSQL
- psycopg2
- PyYAML

## Структура проекта

- `main.py` — консольный интерфейс
- `dbconnection.py` — подключение к PostgreSQL
- `dbtable.py` — базовые операции с таблицами
- `project_config.py` — загрузка конфигурации
- `tables/stations_table.py` — операции со станциями
- `tables/routes_table.py` — операции с маршрутами
- `schema.sql` — структура БД и начальные данные
- `config.example.yaml` — пример конфигурации
- `requirements.txt` — зависимости Python

## Установка и запуск

### Настройка подключения к PostgreSQL

Для запуска приложения необходимо создать локальный файл `config.yaml` на основе `config.example.yaml`.

Пример содержимого:

```yaml
dbname: postgres
user: postgres
password: "YOUR_PASSWORD"
host: localhost
dbtableprefix: "session_trains."
```

Замените `YOUR_PASSWORD` на пароль своего пользователя PostgreSQL.

Если используются другие база данных, имя пользователя или адрес сервера, измените соответствующие параметры. PostgreSQL должен быть запущен, а пользователь должен иметь права на создание таблиц и изменение данных в выбранной базе.

Файл `config.yaml` содержит личные параметры подключения и не публикуется на GitHub.

### Первый запуск

Выполните `schema.sql` в DBeaver или другом SQL-клиенте, подключенном к выбранной базе данных.

Создайте виртуальное окружение и установите зависимости:

```bash
py -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

Запустите приложение:

```bash
./.venv/Scripts/python.exe main.py
```

При успешном подключении откроется главное меню управления станциями и маршрутами.

Команды для Git Bash в Windows:

```bash
py -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

Запуск приложения:

```bash
./.venv/Scripts/python.exe main.py
```

## База данных

Используется отдельная схема `session_trains`.

Основные таблицы:

- `stations` — название, тарифная зона, порядок на линии
- `routes` — начальная и конечная станции маршрута

Начальный набор данных содержит 6 станций и 5 маршрутов.

## Безопасность

Параметры подключения хранятся в локальном `config.yaml`,
исключенном из Git через `.gitignore`.

SQL-запросы используют параметры psycopg2.
Имена таблиц формируются через psycopg2.sql.Identifier.
