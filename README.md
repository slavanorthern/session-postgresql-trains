
# Сессионный проект по PostgreSQL

## 1. Описание проекта

Консольное приложение на Python для управления станциями и маршрутами пригородных электропоездов.

Проект разработан на основе базы данных из предыдущих домашних заданий по PostgreSQL. В качестве примера используется направление Новосибирск-Главный — Тогучин.

Для выполнения сессионного задания используются две таблицы:

- `stations` — станции, их названия, тарифные зоны и порядок расположения на линии.
- `routes` — маршруты (отдельные рейсы) с начальной и конечной станциями.

Согласно условиям варианта № 5, интерфейс работает только с начальной и конечной станциями. Промежуточные остановки, расписание и тарифы в приложении не рассматриваются.

Разные рейсы могут иметь одинаковые начальную и конечную станции. В интерфейсе они различаются порядковыми номерами строк.

## 2. Функциональные возможности

### Управление станциями

- Просмотр списка станций.
- Добавление новой станции.
- Изменение названия, тарифной зоны и порядка следования.
- Удаление станции с учетом связанных маршрутов.
- Подтверждение удаления связанных объектов.

### Управление маршрутами

- Просмотр маршрутов выбранной станции.
- Добавление маршрута с выбором начальной и конечной станций.
- Удаление маршрута по порядковому номеру записи.

### Проверки и безопасность

- Проверка обязательных полей, типов и диапазонов значений.
- Ограничение длины названий станций.
- Обработка ошибок PostgreSQL.
- Контроль уникальности и внешних ключей.
- Параметризованные SQL-запросы для защиты от SQL-инъекций.
- Транзакции с откатом изменений при ошибках.
- Отсутствие ввода суррогатных ключей пользователем.

Постраничный просмотр и изменение маршрутов относятся к дополнительным заданиям и не реализованы.

## 5. Инструкция по установке и запуску

Инструкция предназначена для Windows с использованием Visual Studio Code и Git Bash.

### Шаг 1. Подготовка проекта

Скачайте ZIP-архив проекта и распакуйте его в отдельную папку.

Откройте папку проекта в Visual Studio Code.

Необходимо иметь установленные Python и PostgreSQL.

### Шаг 2. Установка зависимостей

Откройте Git Bash в корневой папке проекта.

Создайте виртуальное окружение:

```bash
py -m venv .venv
```

Установите необходимые библиотеки:

```bash
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

### Шаг 3. Настройка подключения к PostgreSQL

В корневой папке проекта создайте файл `config.yaml` на основе `config.example.yaml`.

Пример содержимого:

```yaml
dbname: postgres
user: postgres
password: "YOUR_PASSWORD"
host: localhost
dbtableprefix: "session_trains."
```

Замените `YOUR_PASSWORD` на пароль своего пользователя PostgreSQL.

Параметры подключения:

- `dbname` — название базы данных.
- `user` — имя пользователя PostgreSQL.
- `password` — пароль пользователя PostgreSQL.
- `host` — адрес сервера PostgreSQL.
- `dbtableprefix` — название схемы с точкой в конце.

Если используется другой пользователь или база данных, необходимо изменить соответствующие параметры.

Например:

```yaml
dbname: university
user: student
password: "my_password"
host: localhost
dbtableprefix: "session_trains."
```

Пароль в примере является условным. На другом компьютере нужно указать собственные учетные данные PostgreSQL.

Пользователь PostgreSQL должен иметь необходимые права на создание схемы и таблиц, а также на чтение и изменение данных.

**Важно:** файл `config.yaml` содержит учетные данные и исключен из Git с помощью `.gitignore`. Он не включается в итоговый архив.

### Шаг 4. Создание базы данных

Запустите PostgreSQL и откройте DBeaver.

Подключитесь к базе данных, указанной в `config.yaml`. Если такая база данных еще не существует, создайте ее.

Откройте SQL-редактор и выполните содержимое файла `schema.sql`.

Скрипт создаст схему `session_trains` и две таблицы:

- `stations`
- `routes`

Будут добавлены исходные данные:

- 6 станций.
- 5 маршрутов.

Скрипт не удаляет существующие таблицы. Повторно выполнять его после начала работы с пользовательскими данными не требуется.

### Шаг 5. Запуск приложения

В Git Bash из корневой папки проекта выполните:

```bash
./.venv/Scripts/python.exe main.py
```

При успешном подключении появится главное меню:

```text
ПРИГОРОДНЫЕ ПОЕЗДА: УПРАВЛЕНИЕ ДАННЫМИ

1 - просмотр станций
2 - добавление станции
3 - изменение станции
4 - удаление станции
5 - маршруты выбранной станции
9 - выход
```

Для выбора станций и маршрутов используются порядковые номера записей на экране.

Пользователь не вводит значения `station_id` и `route_id`.

## 6. Архитектура и безопасность

Приложение использует объектно-ориентированный подход.

Классы `StationsTable` и `RoutesTable` наследуются от базового класса `DbTable`.

SQL-запросы выполняются с помощью библиотеки psycopg2.

Пользовательские значения передаются отдельно от SQL-запросов через параметры. Имена схемы и таблиц формируются с использованием `psycopg2.sql.Identifier`.

Операции изменения данных выполняются в транзакциях с возможностью отката при возникновении ошибки PostgreSQL.

При удалении станции, имеющей связанные маршруты, программа запрашивает подтверждение пользователя.
